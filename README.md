# TCC ITA — Modelagem de Dados do SUS com Ciência de Dados

Este repositório é parte do Trabalho de Conclusão de Curso (TCC) do Instituto Tecnológico de Aeronáutica (ITA), com foco na **análise e modelagem de informações de saúde pública do SUS (Sistema Único de Saúde)**, utilizando técnicas de **Ciência de Dados**.

---

## 📁 Estrutura do projeto

```bash
.

├── notebooks_exploracao/   # Notebooks de análise exploratória (EDA)
├── notebooks_modelagem/    # Notebooks de modelagem estatística e preditiva
├── src/                    # Código-fonte em Python (classes e funções reutilizáveis)
├── pyproject.toml          # Configuração de build do projeto (PEP 621)
├── requirements.txt        # Dependências do projeto
